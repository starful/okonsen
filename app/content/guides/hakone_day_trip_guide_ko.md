## 한눈에 (3줄)

*   **소요:** 신주쿠 → 하코네유모토 약 85~120분. 당일은 **목욕 한 블록(2~3시간)** 에 집중하는 편이 낫습니다.
*   **비용감(1인):** 왕복+패스·특급 대략 ¥5,000~9,000대 + day-use 입장 ¥1,500~3,500(+ 전세탕 시 추가).
*   **추천 동선:** 오전 입성 → 유모토 점심 → **오후 day-use** → 여유 있으면 고라 짧게 → 저녁 귀경.

이 페이지는 소개 글입니다. 숙소·투어 예약은 위/아래 **Klook·라쿠텐** 버튼으로 외부에서 검색하세요.

## Free Pass를 살 것인가

**Hakone Free Pass(보통 2일권)** 는 오다큐 왕복(지정 발매역~오다와라) + 하코네 구간 교통(등산전차·케이블·로프웨이·아시노코 유람선·지정 버스 등)이 묶입니다. 당일이라도 2일권을 사는 경우가 많습니다.

| 상황 | 선택 |
|------|------|
| 유모토에서 day-use만, 로프웨이·호수 안 탐 | 패스 없이 왕복만도 가능. 요금 비교 후 결정 |
| 고라·오와쿠다니·아시노코까지 이을 계획 | **Free Pass 추천** |
| 좌석·시간 고정하고 편히 입성 | 패스 + **로망스카 특급권** 추가 (패스만으로 특급 대체 불가) |

*   구매: 신주쿠 오다큐 여행센터, 오다와라, 또는 온라인 수령형.
*   로망스카는 **전 좌석 지정** — 주말·연휴는 먼저 예약.
*   유효는 구매일부터. 분실 재발행 없음.

## 신주쿠 → 유모토

| | 로망스카 | 급행/쾌속급행 |
|--|----------|----------------|
| 시간 | 약 80~90분 | 약 1시간 45분~2시간 |
| 환승 | 유모토 직통 | 오다와라에서 등산전차 환승 |
| 비용 | 운임(패스 포함분) + 특급 약 ¥1,200대 | 패스만으로 가능 |

유모토역에 코인로커가 있습니다. 큰 짐은 맡기고 목욕만 다니는 편이 편합니다.

## 오후 목욕: day-use 두 곳

당일 핵심은 **숙박 없이 쓰는 온천**입니다. 아래 두 곳이 유모토 기준으로 자주 묶입니다. 요금·시간은 변동하니 **방문 당일 시설 공지**를 확인하세요.

### 하코네 유료 (箱根湯寮)

*   **포인트:** 자연형 노천 + **전세탕(貸切) 다수**. 타투·프라이버시 이슈면 전세탕 우선.
*   **접근:** 유모토역 무료 셔틀(간격은 현지 안내).
*   **요금감:** 대중탕 대략 ¥1,500~2,000대 / 전세탕 1시간 대략 ¥4,000~6,000대(+ 입장 별도인 경우 있음).
*   **팁:** 주말 전세탕은 오자마자 예약하거나, 가능하면 사전 확인.

### 텐세이엔 (天成園) day-use

*   **포인트:** 대형 료칸의 **옥상 노천**, 휴게 공간 넓음. 역에서 도보 또는 셔틀.
*   **요금감:** day-use 대략 ¥2,500~3,000대(수건 포함 여부 확인).
*   **팁:** 운영·청소 시간대가 있으니 도착 전 최종 입장 시각 확인. 24시간 표기와 실제 day-use 가능 시간은 다를 수 있습니다.

유모토 숙박·객실탕이 궁금하면 OKOnsen 상세:

*   [하코네 팍스 요시노](/onsen/hakone_pax_yoshino_ko) — 유모토, 객실 노천·가족탕
*   [하코네 스이메이소](/onsen/hakone_suimeisou_ko) — 전망·가족탕 중심

지도에서 Private만 보려면 [OKOnsen 지도(한국어)](/?lang=ko) → **가족탕** 필터.

## 여유 있을 때만: 고라·호수

목욕 후 90분 이상 남으면:

1. 등산전차로 **고라**
2. (날씨 좋을 때) 로프웨이·오와쿠다니 — 가스·운무로 전망은 운
3. 무리해서 해적선까지 다 넣지 말 것 — 당일은 **목욕 품질 > 명소 개수**

## 당일 타임테이블 예시

| 시간 | 할 일 |
|------|--------|
| 08:00 | 신주쿠 출발 (로망스카면 특급 예약 확인) |
| 09:30~10:00 | 유모토 도착, 로커, 패스 수령/개통 |
| 10:30~12:00 | 상점가·강변 가볍게 (선택) |
| 12:00~13:00 | 점심 |
| 13:00~16:00 | **유료 또는 텐세이엔** (전세탕이면 예약 시각 고정) |
| 16:00~17:30 | 휴식·기념품, 또는 고라 짧게 |
| 17:30~ | 저녁 / 귀경 열차 (막차·로망스카 시간 먼저 고정) |

프리패스로 오와쿠다니까지 욕심내면 목욕 시간이 줄어듭니다. **첫 방문 당일 = 온천 1곳 + 귀경**이 실패가 적습니다.

## 준비물·매너 (짧게)

*   작은 타월 + (대여 싫으면) 큰 타월, 갈아입을 옷, 보습
*   탕 들어가기 전 샤워, 수건은 탕에 넣지 않기
*   문신: 시설마다 다름 → **전세탕** 또는 사전 확인. 자세한 목록은 [타투 가능 온천](/guide/tattoo_friendly_onsen_list_ko), 기본 규칙은 [온천 매너](/guide/onsen_etiquette_basics_ko)
