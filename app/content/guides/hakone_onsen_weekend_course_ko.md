## 한눈에 (3줄)

*   **추천 형태:** **1박 2일**. 당일만 가능하면 [당일 가이드](/guide/hakone_day_trip_guide_ko)가 더 맞습니다.
*   **교통:** 주말·연휴면 **Hakone Free Pass 2일권** + (원하면) 로망스카 특급. 고라·로프웨이·호수를 이을수록 패스 이득이 큽니다.
*   **리듬:** Day1 입성 → 체크인·첫 목욕 → Day2 로프웨이/호수(선택) → 아침 목욕 또는 유모토 day-use → 귀경.

이 페이지는 소개 글입니다. 숙소·투어 검색은 **Klook·라쿠텐** 버튼으로 외부에서 하세요. 요금·운행은 시즌마다 바뀌니 출발 전 공식 안내를 확인하세요.

## 1박 vs 당일

| | 당일 | 1박 (이 코스) |
|--|------|----------------|
| 목욕 | 오후 1블록 | 저녁+아침(+ 선택 day-use) |
| 동선 | 유모토 중심 | 유모토 → **고라 또는 아시노코** |
| Free Pass | 선택 | **2일권 추천** |
| 누구에게 | 일정 빡센 도쿄 여행 | 주말·연휴에 “온천이 목적” |

문신·프라이버시가 중요하면 숙소 상세에서 **가족탕(貸切)·객실탕**을 먼저 보고, 대중탕만 있는 플랜은 피하세요.

## Free Pass·입성 (주말용)

*   **2일권**이 기본. 발매 시각부터 유효하니, 금요일 밤 입성이면 패스 개통 타이밍을 미리 계산하세요.
*   신주쿠 → 유모토: 로망스카 약 85분(특급 별도) / 급행+환승 약 2시간.
*   주말 로망스카·인기 료칸은 **먼저 마감**됩니다.
*   패스에 포함되는 것(등산전차·케이블·로프웨이·아시노코 유람선·지정 버스 등)과 **특급·일부 버스 제외**는 [당일 가이드 Free Pass 절](/guide/hakone_day_trip_guide_ko)과 동일합니다.

큰 짐: 유모토에서 바로 고라·호수로 가면 숙소 셔틀/택시 여부를 상세 페이지에서 확인. 유모토에 짐을 두고 day-use만 할 거면 역 로커도 옵션.

## 숙소 레인 고르기 (3갈래)

예산·분위기로 **하나만** 고르고, 나머지는 보지 않는 편이 빠릅니다. 예약 전 각 페이지에서 문신·가족탕·식사 포함 여부를 확인하세요.

### A. 모던 럭셔리 — 고라

[호텔 인디고 하코네 고라](/onsen/hotel_indigo_hakone_gora_ko)

*   **이런 분:** 전통 료칸보다 현대 호텔·프라이빗 온천·산 뷰.
*   **위치 감:** 고라 권역. 유모토에서 등산전차·버스 후 이동.
*   **주말 팁:** 체크인 전 시간이 남으면 유모토 점심만 하고 올라가기 vs 바로 고라 입성 후 숙소 목욕 — 둘 중 하나만.

### B. 황실 정원·최고급 — 고라

[하코네 고라 가단](/onsen/hakone_gora_kadan_ko)

*   **이런 분:** 가이세키·정원·전용 노천이 목적인 기념일·스페셜 트립.
*   **위치 감:** 고라, 미술관·산책과 묶기 좋음.
*   **주말 팁:** 성수기는 수개월 전 마감 흔함. 객실 타입(노천 유무)을 예약 단계에서 고정.

### C. 호수·후지 전망 — 아시노코

[더 프린스 하코네 아시노코](/onsen/the_prince_hakone_lake_ashinoko_ko)

*   **이런 분:** 아시노코·해적선·신사와 같은 축에서 자고 싶을 때.
*   **위치 감:** 호수 남안 쪽. Day2 로프웨이·유모토 귀경과 동선이 A/B와 다름.
*   **주말 팁:** 전망·프라이빗 온천 객실은 타입을 꼭 확인. 날씨에 후지 가시성은 운.

### 유모토에 묵고 싶을 때

고라·호수까지 안 가고 **관문에서 끝내기**:

*   [하코네 팍스 요시노](/onsen/hakone_pax_yoshino_ko) — 객실 노천·가족탕
*   [하코네 스이메이소](/onsen/hakone_suimeisou_ko) — 전망·휴식

지도에서 고르려면 [OKOnsen 한국어 지도](/?lang=ko) → Private / Luxury 필터 → Compare.

## Day 1 — 도착 · 체크인 · 첫 목욕

예시(토요 입성). 열차·체크인 시각에 맞춰 앞뒤로 미루세요.

| 시간 | 할 일 |
|------|--------|
| 09:00~10:00 | 신주쿠 출발 (로망스카면 특급 확인) |
| 10:30~11:30 | 유모토 도착. Free Pass 개통. 점심 또는 바로 이동 |
| 12:00~14:00 | **레인 A/B:** 고라로 이동 → 체크인 대기·산책 / **레인 C:** 아시노코 방면 이동 |
| 15:00~ | 체크인 후 **숙소 목욕(첫 블록)**. 무리한 명소 추가보다 목욕·석식 |
| 저녁 | 가이세키·호텔식. 익일 로프웨이·막차는 앱/안내판으로 미리 북마크 |

**당일로 바꾸려면:** 체크인 없이 유모토 [day-use(유료·텐세이엔)](/guide/hakone_day_trip_guide_ko) 한 블록 후 귀경. 고라까지 욕심내지 않기.

## Day 2 — 로프웨이 · 두 번째 목욕 · 귀경

| 시간 | 할 일 |
|------|--------|
| 아침 | 숙소 조식 + **아침 목욕**(가능하면 여기가 2번째 블록) |
| 09:00~12:00 | (선택) 고라 → 오와쿠다니·토겐다이 **로프웨이**. 가스·구름으로 전망은 기대를 낮게 |
| 또는 | 아시노코 짧은 산책·유람선 한 구간만 (패스 구간 확인) |
| 12:00~14:00 | 점심 후 유모토 하행. 짐·체크아웃 동선 먼저 |
| 14:00~16:00 | (선택) 유모토 **day-use**로 마지막 목욕 — 시간이 빠듯하면 생략 |
| 16:30~ | 신주쿠행. **막차·로망스카 예약 시각을 오전 중에 확정** |

로프웨이·해적선·목욕을 **하루에 다** 넣으면 이동만 하다가 끝납니다. Day2는 **전망 하나 + 목욕 하나 + 귀경**이 실패가 적습니다.

## 유모토 day-use (귀경 전 옵션)

숙소 아침 목욕으로 충분하면 건너뛰세요. “한 번 더”가 필요할 때만:

*   하코네 유료 — 전세탕·자연 노천 (주말 전세는 일찍 마감)
*   텐세이엔 — 옥상 노천·휴게 공간

요금감·셔틀·주의사항은 [당일 가이드 day-use 절](/guide/hakone_day_trip_guide_ko)을 그대로 쓰면 됩니다.

## 예산·예약 체크리스트

*   교통: Free Pass 2일 + (선택) 로망스카 왕복 특급  
*   숙소: 주말 석식 포함 플랜이 기본인 료칸이 많음 → 총액은 **1박 2인 기준**으로 볼 것  
*   day-use: 1인 ¥1,500~3,500대(+ 전세탕)  
*   예약 순서 추천: **숙소 → 로망스카 → (필요 시) 전세탕·패스**  
*   알레르기·문신·어린이 동반은 예약 메모/상세 정책 확인  

## 준비물·매너 (짧게)

*   작은 타월, (대여 싫으면) 큰 타월, 보습, 방수 타투 커버(필요 시)
*   산간·호숫가는 도쿄보다 기온 — 얇은 겉옷
*   탕 전 샤워, 수건 입수 금지. 상세 매너는 [온천 매너](/guide/onsen_etiquette_basics_ko), 타투는 [타투 가능 목록](/guide/tattoo_friendly_onsen_list_ko)
